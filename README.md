# 🌲 Guará-App

Um projeto cultural interativo desenvolvido para preservar e promover a história, os símbolos e as lendas de Guarapuava, Paraná.

## 📱 Sobre o Projeto
Este aplicativo foi concebido como uma ferramenta de educação patrimonial. Ele permite que moradores e turistas explorem as riquezas da "Terra do Lobo Bravo" de forma moderna e intuitiva.

---

## ✨ Funcionalidades Atualizadas

### 📖 Contos da Nossa Terra (Lendas)
Uma curadoria especial de narrativas que moldaram o imaginário guarapuavano, com visual focado em leitura imersiva e créditos históricos:
* **Lagoa das Lágrimas:** O conto de fidelidade e amor dos índios Dorin (Relatado por Nivaldo Krüger).
* **Capela do Degolado:** A história de fé e justiça popular em torno do Pobre Diabo.
* **A Serpente da Lagoa:** O folclore urbano sobre o despertar da fera e a preservação da Catedral.

### 🏛️ Símbolos e História
* **Hino Municipal:** Letra completa e história dos autores.
* **Curiosidades:** Fatos históricos sobre a fundação, a geologia e os marcos da cidade.
* **Quiz Interativo:** (Em desenvolvimento) Um desafio de conhecimentos para testar o que o usuário aprendeu sobre a cidade.

## 🚀 Tecnologias Utilizadas
* **React Native** com **Expo**
* **Expo Router** (Navegação baseada em arquivos)
* **Moti** (Animações fluidas de interface)

* **EAS Build** (Distribuição de APKs nativos)

## 🛠️ Como rodar o projeto localmente

1. Clone o repositório:
   ```bash
   git clone [https://github.com/leonardohirt/APP-Guarapuava.git](https://github.com/leonardohirt/APP-Guarapuava.git)

   ```
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Inicie o servidor Expo:
   ```bash
   npx expo start
   ```
4. 
 Escaneie o QR Code com o app Expo Go no Android ou iOS.
